# 🎮 Game Arcade

A fun, interactive game site hosting mini-games — built to learn DevOps by shipping one project five different ways.

## Games
- Tic-Tac-Toe — play with a friend or computer (Easy / Medium / Hard)
- Connect Four — play with a friend or computer (Easy / Medium / Hard)
- Sliding Puzzle — solo, with moves and timer
- Chess — 2-player, play with a friend or computer (Easy / Medium / Hard)

## Accounts
Sign up / log in to save your games to My Games, or Continue as Guest to play without an account. Guest games are only saved in that browser.

Week 1 is browser-only. Week 2 adds a real backend with Docker.

## How to run it
Open `index.html` in your browser, or run it from Docker (Week 2).

## How to play
Pick a game from the home page. For tic-tac-toe, Connect Four, and chess, choose Play with a Friend or Play with Computer first.

## What I learned
Git, GitHub, HTML, CSS, JavaScript, game logic, localStorage, and shipping a real project.
